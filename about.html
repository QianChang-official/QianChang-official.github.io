关于本站

这里是 Qianchang 的个人站点，聚焦于工程实践、系统设计与前沿技术研究的交叉地带。

我相信长期工程思维的价值——不追求一次性的 demo，而是构建可持续演进、可维护、可观测的系统。在这个站点上，你可以找到：

  • 技术博客：对学术论文的深入解读与工程实现启示
  • 项目展示：从概念到部署的完整系统实现
  • 音源控制台：基于 Web Audio API 与 Cloudflare R2 的网页音频工作台

研究方向

当前关注的核心领域包括：

  • 大语言模型智能体（LLM Agents）的推理与决策机制
  • 贝叶斯推断与主动学习在交互系统中的应用
  • 量子计算误差消减与动态电路优化
  • 分布式系统与无服务器架构（Serverless / Edge Computing）

技术栈

本站基于纯静态架构重构，无构建工具，直接部署于 GitHub Pages，通过 Cloudflare 进行 DNS 管理与边缘加速。音源控制台使用原生 Web Audio API，后端存储依托 Cloudflare R2 + Workers。
